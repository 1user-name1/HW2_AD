# Задачи про скобки и анаграммы

## Valid Parentheses

Проверяем строку слева направо. Открывающие скобки кладём в стек, а для закрывающей смотрим на последнюю открытую. Если пары нет или она не подходит, строка неправильная. В конце стек должен быть пустым.

Стек нужен потому, что закрывающая скобка относится к последней открытой: это порядок LIFO — «последним пришёл, первым вышел».

- Время: **O(n)** — каждый символ проверяется один раз.
- Память: **O(n)** — в худшем случае в стеке окажутся все открывающие скобки.

Агент тоже выбрал стек и оценил время как **O(n)**. Я получил ту же оценку: строку проходим один раз.

Примеры запуска:

```text
'()'      -> True
'()[]{}'  -> True
'(]'      -> False
'([)]'    -> False
'{[]}'    -> True
```

Решение находится в файле [`valid_parentheses.py`](./valid_parentheses.py).

## Дополнительная задача: Group Anagrams

Для каждой строки считаем, сколько раз встречается каждая буква. Получившийся набор чисел используем как ключ в словаре. У анаграмм ключ одинаковый, поэтому они попадают в одну группу.

- Время: **O(n · k)**, где `n` — количество слов, а `k` — длина самого длинного слова.
- Память: **O(n · k)** — словарь хранит слова и ключи их групп.

Пример:

```text
['eat', 'tea', 'tan', 'ate', 'nat', 'bat']
-> [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

Решение находится в файле [`group_anagrams.py`](./group_anagrams.py).
